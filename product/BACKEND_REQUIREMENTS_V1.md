# 呼吸森林 AI 小助手 V1 后端产品需求

## 1. 文档目的

本文把 V1 用户场景拆解为后端能力和共享契约需求，不规定后端内部实现结构。共享契约由协调窗口最终维护；本文中的字段和状态语义均为产品侧输入，达到 `accepted` 前不得作为稳定依赖。

## 2. 后端能力需求

### BR-001 输入保护

- 拒绝空输入、无效格式和超过契约上限的输入；
- 对提示注入和绕过安全策略的文本执行基础防护；
- 输入异常不得触发模型、计划编译或设备执行；
- 中文文本和 JSON 显式使用 UTF-8。

### BR-002 当前会话最小状态

按会话维护以下最小状态：

- 当前话题；
- 最近唯一设备；
- 当前唯一任务 ID；
- 待澄清问题及原始请求关联；
- 当前唯一待确认计划。

后端不得自动保存长期偏好，不得把历史聊天文本当成当前设备事实。临时状态应支持完成、取消、过期和会话结束后的清理。

### BR-003 意图识别与路由

- 本地规则优先识别确认、取消、停止、暂停、恢复、明确设备开关、状态查询和任务查询；
- 其余自然语言可调用模型提取候选意图及用户原话证据；
- 模型输出必须经过结构校验和固定路由；
- V1 至多处理一个执行意图，不支持任意多意图组合。

### BR-004 可信设备注册表

- 维护稳定设备 ID、用户可见名称、别名、空间、连接状态、可用动作和当前状态版本；
- V1 可控设备仅为空气净化器、智能窗户和抽油烟机；
- 智能窗户使用 `open` / `closed`，其他开关设备使用 `on` / `off`；
- 新风系统、加湿器和循环风机返回“待接入”，不可进入执行计划；
- 名称解析不唯一时返回澄清，不由模型决定最终设备 ID。

### BR-005 可信环境快照

- 提供 `PM2.5`、`CO2`、湿度、温度、空气评分、观测时间和数据来源；
- 按共享契约定义新鲜度；
- 缺失、无效或过期时返回明确不可用状态，不让模型补值；
- Mock 数据必须保留来源标识直至用户回复。

### BR-006 确定性计划与策略裁决

- 根据已校验意图生成可复现的执行计划；
- 策略至少支持：允许、需要确认、需要澄清、拒绝；
- 净化器、抽油烟机和智能窗户的明确幂等开关可在策略允许时直接执行；智能窗户直接执行仍必须完成设备能力校验、状态版本校验、策略裁决、可信执行回执与来源标识；
- 场景创建、模拟优化任务创建和任务替换必须确认；
- 设备不可用、动作不支持、越权或超出 V1 范围时不得执行。

### BR-007 确认管理

待确认计划至少绑定：

- 会话和用户；
- 计划标识或计划哈希；
- 用户可见摘要；
- 相关设备状态版本和当前任务版本；
- 创建时间和失效时间；
- 确认、取消或失效状态。

确认时必须重新校验计划、状态版本、任务冲突和策略。没有有效待确认计划的“确认”不得执行历史动作。

### BR-008 唯一任务状态机

- 同一作用域同时至多一个待运行、运行或暂停任务；
- 支持烹饪守护任务及 `comfort`、`balanced`、`eco` 三种模拟优化任务；
- 支持查询、暂停、恢复和停止；
- 状态至少可区分：待确认、待运行、运行、暂停、停止、失败；
- 状态迁移需要幂等；恢复前重新校验依赖和策略；
- 新任务冲突时返回替换确认，不静默覆盖；旧任务停止失败时不得创建新任务；
- 停止任务不自动反转已经完成的设备动作。

### BR-009 当天时间解析与调度

- 支持“立即开始”和用户家庭时区内当天未来的明确时间；
- 在确认摘要中返回具体时间和时区；
- 拒绝过去、含糊、跨日和循环时间；
- 到达触发时间时重新校验设备状态、任务版本和策略。

### BR-010 固定烹饪场景

- 场景模板固定包含抽油烟机开启和空气净化器开启；
- 只有用户在本次计划中明确选择且策略允许时，才能加入智能窗户状态改变；
- 必要设备不可用时不得创建任务；
- 模型只能提供场景和参数证据，不能修改模板；
- 多动作结果按项目记录，支持部分成功语义。

### BR-011 Mock/Replay 模拟优化

- 仅支持 `mock` 或 `replay`，拒绝 `live_model` 和自定义权重；
- 固定三种模式的目标、权重、健康底线和可控设备范围；
- 优化输出只能作为候选动作；
- 候选动作必须经过动作屏蔽、策略裁决和执行器；
- 屏蔽离线、未接入、越权、不支持或受约束的设备动作；
- 没有合法候选动作时记录“本轮无执行”，不得伪造收益或回执。

### BR-012 执行器、幂等与可信回执

- 执行请求包含稳定请求标识和幂等键；
- 执行前检查当前状态，目标已满足时返回幂等结果；
- 回执区分请求已受理、执行成功、执行失败、超时和状态未知；
- 回执包含计划、设备、请求动作、实际状态、来源和时间关联；
- 多动作场景提供逐项结果，不能用任务创建成功替代设备执行成功；
- 只有成功回执允许生成成功陈述。

### BR-013 安全回复合成

- 回复只使用经校验的知识结果、当前可信状态、策略结果、任务状态和执行回执；
- 回复模型失败时提供固定模板；
- Mock、Replay、过期、未知和部分成功标识不得在回复合成中丢失；
- 健康内容不做诊断；明显急性不适或危险暴露使用安全引导模板。

### BR-014 独立降级

- 聊天模型故障不应阻断可由固定代码完成的可信状态查询、明确本地控制和任务管理；
- 设备服务故障时禁止执行，但非执行类聊天和知识能力可独立工作；
- 环境服务故障时不猜测环境数值；
- Mock/Replay 故障时不得创建新的模拟优化任务或继续产生候选动作；
- 任一故障不得绕过确认有效期、状态版本、动作屏蔽或策略复核。

### BR-015 日志与可观测性

- 记录请求追踪标识、稳定错误语义、任务状态迁移和脱敏执行结果；
- 不记录密钥、完整敏感对话、未脱敏个人信息或可直接执行的凭据；
- Mock/Replay 与未来真实来源在日志中可区分；
- 运营事件只发送共享契约允许的最小字段。

## 3. 需要协调窗口评审的共享契约

现有 v0.1 契约不足以承载 V1。产品侧请求协调窗口组织以下语义评审：

1. 会话：响应类型、待确认、待澄清、任务摘要、执行结果和来源标识；
2. 语义意图：候选意图、用户原话证据和校验状态；
3. 设备：规范状态、动作、状态版本、连接状态和执行请求；
4. 环境：数据新鲜度、不可用原因和来源传播；
5. 计划与策略：计划摘要、策略裁决、风险原因和替代建议；
6. 确认：计划绑定、状态版本、有效期、确认、取消和失效；
7. 任务：任务类型、模式、场景、计划时间、状态、替换与状态迁移；
8. 执行回执：逐项动作、实际状态、幂等、失败、超时和部分成功；
9. 错误：输入无效、意图不明、确认失效、任务冲突、设备不可用、环境不可用、执行失败和依赖故障；
10. 事件：确认展示/确认/取消、澄清、任务创建/状态迁移、动作结果和降级，同时禁止记录完整对话与敏感信息。

具体字段名、错误代码和版本兼容策略由受影响工作线共同确认后，再由协调窗口写入 `shared/**`。

## 4. 后端验收输入

后端实现应以 `PRD.md`、`USER_FLOWS.md` 和 `ACCEPTANCE_CRITERIA.md` 为产品验收输入，不得以后端当前实现反向缩减行为、异常路径或安全边界。
