# D-2026-08-03 · AI 小助手 V1 产品范围与安全边界

- 状态：正式生效
- 决策人：产品负责人
- 日期：2026-08-03
- 影响范围：产品、前端、后端、运营与共享契约

## 背景

当前主线只保留现有 UI 作为产品与视觉基线。AI 对话、设备接入、后端服务、数据链路和运营能力需要基于新需求重新定义，不能继承旧 AI V1、Phase A 或旧 DQN 路线。

## 决策

1. 新 V1 是下一阶段目标规格，不代表当前 UI Mock 已实现；
2. V1 单设备控制范围为：空气净化器、智能窗户和抽油烟机；新风系统、加湿器和循环风机保持“待接入”；
3. 明确、低风险、幂等的空气净化器或抽油烟机开关可在策略允许时直接执行；智能窗户状态改变、固定场景、模拟优化任务和任务替换必须确认；
4. 固定烹饪/火锅守护支持立即开始或当天未来明确时间开始，持续至用户停止；不支持跨日排程和复杂条件；
5. AI 对话可以接入模型 API，但模型输出不得直接执行；模型不可用时，可信状态查询和高确定性本地控制可以独立降级；
6. V1 优化任务只允许 Mock 或 Replay，必须展示“模拟优化”，不得宣称真实 DQN、真实设备控制或真实收益；
7. V1 同时只允许一个活动任务；创建冲突任务时必须询问是否替换，不得静默覆盖；
8. 烹饪守护与三种优化模式先通过 AI 对话提供，快捷场景 UI 调整作为前端后续需求；
9. 空气健康内容只提供一般性信息，不做诊断或替代医疗建议；明显急性不适或危险暴露应建议用户先离开风险环境并寻求专业帮助。

## 关键约束

- 模型理解结果、系统执行计划和可信执行回执必须分离；
- 设备 ID、能力、当前状态、安全策略、确认有效性、任务状态与执行结果由固定代码和可信数据决定；
- 没有成功回执时不得声称动作成功；
- 当前会话只保留完成确认、澄清和简单指代所需的最小状态；
- Mock、Replay、过期数据和未知状态必须如实标识。

## 跨线影响

- 协调窗口需要登记并版本化 V1 所需共享契约；
- 前端需要新增确认、澄清、任务状态、模拟标识和部分成功等呈现；
- 后端需要实现确定性计划、安全策略、确认管理、唯一任务状态机、设备与环境可信状态、Mock/Replay 适配和执行回执；
- 运营需要定义脱敏事件、降级文案和发布能力声明。

## 不在本决策范围

多设备自由计划、多任务、跨日排程、复杂条件、长期记忆、自定义优化权重、真实 MQTT、DQN `live_model`、跨家庭权限和生产收益验证。
