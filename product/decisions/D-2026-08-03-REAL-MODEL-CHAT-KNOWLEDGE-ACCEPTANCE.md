# D-2026-08-03 · 真实模型 API 聊天与知识问答验收条件

- 状态：正式生效
- 决策人：产品负责人
- 日期：2026-08-03
- 关联变更：`DEP-2026-08-03-002`（协调窗口已接受；当前产品分支尚未同步该登记记录）
- 影响范围：产品验收标准；不修改共享契约 `v1.0.0`

## 决策

1. V1 真实模型 API 仅参与普通聊天与空气健康知识问答的 `message.content` 生成；
2. 模型输出不得改变 `responseType`、`sources` 或计划、任务、确认、回执等业务字段；
3. 模型输出不得直接进入 Executor；
4. 知识回答限定在 V1 可答话题；实时状态、个人医疗、跨会话引用、真实 DQN、真实 MQTT 或真实收益声明等话题必须拒绝或转入对应链路；
5. 明显急性不适或危险暴露时，安全引导优先于一般性知识回答；
6. 模型不可用时使用固定模板明确降级，不假装已回答、不伪造结论。

## 验收口径

修订 `AC-011` 至 `AC-013`，并新增 `AC-014` 至 `AC-019`，覆盖自然语言回复边界、知识话题边界、医疗安全边界和降级口径。

## 与现有文档的关系

- 不修改 `AC-000` 至 `AC-094` 现有编号与语义；
- 环境/设备实时查询继续由 `AC-020` 至 `AC-026` 约束；
- 本决策是产品需求输入，不代表当前实现已经接入真实模型 API；Mock 或本地模板结果不得描述为真实模型回答。
