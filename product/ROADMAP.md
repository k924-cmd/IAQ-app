# 呼吸森林产品 Roadmap

## 当前状态

- 已完成：现有移动端 UI Mock 基线与四线目录；
- 已完成：AI 小助手 V1 产品范围、安全边界、用户流程和目标验收标准；
- 未完成：共享契约评审、前后端实现、契约测试与 V1 产品验收。

## V1 实施顺序

1. 协调窗口登记并评审 V1 跨线契约变更；
2. 共同确认会话状态、语义意图、确认/澄清、任务、计划、回执、错误和事件语义；
3. 协调窗口更新并版本化 `shared/contracts/**`；
4. 前端继续保留明确 Mock 标识，并增加确认、澄清、任务和模拟优化状态呈现；
5. 后端实现本地快速路由、设备注册表、确定性计划、策略裁决、确认管理、任务状态机和可信回执；
6. 接入模型语义理解和回复生成，验证模型输出不能直接执行；
7. 接入 Mock/Replay 优化适配与动作屏蔽，不接入 `live_model`；
8. 增加契约测试、关键路径集成测试和故障降级测试；
9. 产品线依据 `ACCEPTANCE_CRITERIA.md` 验收，运营线核对事件、隐私和发布文案；
10. 全部门禁通过后，才评审 V1 可交付状态。

## V1 后续

- V1.5：多设备计划、多任务、更多固定场景、简单条件和环境历史分析；
- V2：经用户授权的长期偏好、跨会话引用和历史任务模板；
- V3：真实设备、实时传感器、DQN `live_model`、Shadow/Canary 和生产执行闭环。

后续版本不得提前进入 V1 契约或验收范围。
